**What I changed:** I ran `dfc --org chainguard` and applied its output, with one edit. dfc picked `python:3.13-dev`, which the free registry doesn't serve, so I used `latest-dev` instead and pinned it to the digest from `crane digest`:
- Both `FROM` lines are now `cgr.dev/chainguard/python:latest-dev@sha256:e0df0ab3cb72380c82f8c5513538152e822a6d8994252663060adea9fdc450c2`.
- Creating the `app` user now uses `addgroup --system app && adduser --system --ingroup app --no-create-home app`, because the Chainguard image doesn't have `groupadd` or `useradd`.

The runtime stage also uses the `-dev` image, as dfc chose, because it needs a shell to create the `app` user. The plain `:latest` image has no shell.
